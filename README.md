# Optical Dept.

A creative toolkit for optical, glitch and false-colour brand assets: patterns, glitch text, a wireframe globe, a heat-map filter and posters, with SVG, PNG and looping MP4 export. Built with React 19, TypeScript, Vite, Tailwind 4, and **@mikeyi2a/minikit-ui 0.1.11**.

## Run

```sh
npm install
npm run dev -- --host 127.0.0.1
```

Open the local URL printed by Vite. `npm run build` creates the production site in `dist/`.

## Tools

- **Optical patterns:** spiral, radial, concentric rings, hazard stripes and waves; adjust frequency, twist, weight, rotation, scale, repetition and colours.
- **Glitch text:** editable repeated text, displaced horizontal slices, colour offsets, seeded noise blocks and scanlines, with an optional optical pattern layer. Motion preview varies the breakup.
- **Heat map:** local image/video input (a short reference video loads by default), Spectrum/Iron/Acid false-colour palettes, exposure, contrast, band count, blend, softness, inversion and scanlines. Video supports playback and seeking; export a full-resolution PNG frame or a looping MP4 of the first 15 seconds.
- **Globe:** projected 3D wireframe sphere with longitude, axial tilt, grid density, stylised land dots and an editable label. Rotation preview and SVG/PNG export; optional transparent background and diagnostic labels. This exports 2D assets, not a 3D model file.
- **Poster composer:** editable three-line headline and caption, three canvas formats.
- **Motion preview:** optional rotation at 2–30 degrees per second, with pause. Starts still; no automatic flashing. Shuffle randomises layout and colours.
- **Exports:** editable SVG and full-resolution PNG (static frame at the current rotation), plus **Loop · MP4**: a seamless 360° rotation loop at 30fps for patterns, globe, glitch text and posters. Needs a browser with WebCodecs (recent Chrome, Edge or Safari); the button is disabled elsewhere. SVG poster text remains editable and uses local font fallbacks; rendering may vary on other machines.
- **My studies:** save and reopen settings in this browser; download settings as JSON for reference. JSON import is not implemented.

MiniKit powers the sliders, colour pickers, segmented controls, selects, toggles, inputs, buttons, export buttons and save dialog. The app imports MiniKit's stylesheet and Tailwind source registration.

## Starter assets

Ten editable SVGs and `optical-dept-starter.zip` are in `public/assets/`. Download the pack from the My studies page. Regenerate the SVGs with:

```sh
node scripts/generate-assets.mjs
```

Uses Node 24's TypeScript support. The two new overlay assets use transparent backgrounds. These assets use original geometric construction and text.

## Review and verification

```sh
node --test tests/artwork.test.mjs
npm run build
```

Generator tests cover all five families × three formats × four vector modes, finite geometry, escaped user text, deterministic signal noise, effect toggles, captured rotation, thermal colour lookup/alpha/blending, sphere projection, globe labels, and glitch-text slicing. Browser checks cover every tool, exports, saving and reopening studies, and the mobile layout.

## Scope

The shell occupies 100dvh; the control panels scroll independently. Heat map accepts browser-decodable images/videos up to 200 MB; files stay local, are not saved with studies, and need reselecting after reload. Unsupported codecs display an error. Thermal colour is mapped from brightness, not measured temperature. Other tools save settings locally. Motion is preview-only; exports are static. There is no backend, account, or cloud storage. The bundled reference video (`public/references/sample-video.mp4`) is served with the app.

## Teaser video

`videos/optical-teaser/` is a 15-second HyperFrames composition built from these assets (`npm run check`, `npm run render` inside that folder). Audio is generated by `scripts/gen-audio.py`.
